# Expense Tracker (Трекер расходов)

**Автор:** Артем Бурнаев

## Описание программы
**Expense Tracker** — это настольное приложение с графическим интерфейсом (GUI), предназначенное для ведения учета личных финансов. Программа позволяет пользователю фиксировать свои траты, классифицировать их по категориям и анализировать расходы за определенные периоды времени. 

Все данные надежно сохраняются в формате JSON, что обеспечивает их сохранность между сессиями работы.

### Основные функции:
*   **Учет транзакций:** добавление расхода с указанием суммы, категории и даты.
*   **Валидация данных:** автоматическая проверка корректности ввода (сумма должна быть положительной, дата — в правильном формате).
*   **Фильтрация:** просмотр записей по конкретным категориям или временным промежуткам.
*   **Аналитика:** автоматический подсчет общей суммы расходов за выбранный период.
*   **Хранение:** экспорт и импорт данных через JSON-файл.

## Как использовать

### Предварительные требования
Для работы приложения необходим установленный интерпретатор **Python 3.x**.

### Установка и запуск
1.  **Клонируйте репозиторий:**
    ```bash
    git clone [ссылка на ваш репозиторий]
    ```
2.  **Перейдите в папку проекта:**
    ```bash
    cd expense-tracker
    ```
3.  **Запустите приложение:**
    ```bash
    python main.py
    ```

## Примеры использования

### Добавление расхода
1. Введите сумму: `500`.
2. Выберите или введите категорию: `Транспорт`.
3. Укажите дату: `2023-10-25`.
4. Нажмите кнопку **«Добавить расход»**. Запись мгновенно появится в таблице.

### Фильтрация и расчет
*   **Сценарий:** Чтобы узнать, сколько денег ушло на еду за прошлую неделю, выберите в фильтре категорию `Еда` и установите диапазон дат. Программа автоматически обновит таблицу и покажет итоговую сумму в поле «Итого».

### Тестирование валидации
*   Если вы попытаетесь ввести в поле суммы текст или отрицательное число (например, `-100`), программа выдаст предупреждение и не добавит запись.
*   При вводе некорректной даты (например, `32.13.2023`) приложение попросит исправить формат.
